# Правила разработки TG Player

## Архитектура хранения медиа и файлов
- **На сервере локально хранится ТОЛЬКО база данных (SQLite `tg_player.db`).**
- **Все медиафайлы (треки, голосовые, обложки плейлистов, аватарки пользователей и т.д.) хранятся в Telegram:**
  - Файлы отправляются ботом в подключенный Telegram-канал пользователя (или в PM боту как fallback).
  - Приложение сохраняет только `file_id` в базе данных.
  - Раздача медиа и картинок клиентам производится через потоковые прокси-роуты (`/api/images/{file_id}`, `/api/player/audio/{file_id}`).
  - Запрещено сохранять пользовательские медиафайлы (обложки, треки, аватары) в локальную файловую систему сервера.
