# Правила разработки TG Player

## Архитектура хранения медиа и файлов
- **На сервере локально хранится ТОЛЬКО база данных (SQLite `tg_player.db`).**
- **Все медиафайлы (треки, голосовые, обложки плейлистов, аватарки пользователей и т.д.) хранятся в Telegram:**
  - Файлы отправляются ботом в подключенный Telegram-канал пользователя (или в PM боту как fallback).
  - Приложение сохраняет только `file_id` в базе данных.
  - Раздача медиа и картинок клиентам производится через потоковые прокси-роуты (`/api/images/{file_id}`, `/api/player/audio/{file_id}`).
  - Запрещено сохранять пользовательские медиафайлы (обложки, треки, аватары) в локальную файловую систему сервера.

## 🎨 Стандарты UI/UX и Дизайн-Система: Dark Neumorphism (Hi-Fi Soft UI)

Любые новые интерфейсы, компоненты и доработки фронтенда в `webapp/` ОБЯЗАНЫ следовать стилю **Dark Neumorphism (эстетика премиальной Hi-Fi аппаратуры / Nokia XpressMusic)**.

### 1. Архитектура стилей и токенов
- **Единый источник правды:** файл `webapp/src/styles/design-system.css` и гайд `webapp/src/styles/DESIGN_SYSTEM.md`.
- **Запрещено:** хардкодить случайные hex-цвета, «плоские» рамки (`border: 1px solid #333`), унылые серые прямоугольники без теней и глубины.
- **Поверхности (Surface hierarchy):**
  - `--c-bg-0` (`#0D0D0D`) — глубокий фон холста/подложки.
  - `--c-bg-1` (`#121212`) — базовый фон приложения.
  - `--c-bg-2` (`#1A1A1A`) — приподнятые выпуклые карточки и панели.
  - `--c-bg-3` (`#222222`) — интерактивные элементы и ховеры.
  - `--c-bg-4` (`#2A2A2A`) — активные поверхности.
- **Акцентный цвет:**
  - `--c-accent` (`#1db954` — Spotify/XpressMusic Green) / `--c-secondary` (`#00BCD4` — Neon Cyan).
  - `--c-accent-glow`: `rgba(29, 185, 84, 0.4)` для светодиодной подсветки.
- **Неоморфные тени:**
  - Выпуклые (convex): `box-shadow: 5px 5px 10px var(--sh-dark), -3px -3px 6px var(--sh-light);`
  - Вдавленные (concave/inset): `box-shadow: inset 3px 3px 6px var(--sh-inset-dark), inset -2px -2px 4px var(--sh-inset-light);`
  - Тонкий световой контур: `border: 1px solid rgba(255, 255, 255, 0.02-0.04);`

### 2. Обязательные правила для компонентов
- **Кнопки (`.neu-btn-icon`, `.neu-btn-primary`, `.neu-btn-rubber`):**
  - В покое — мягко выпуклые (`extruded`).
  - При нажатии (`:active`) — физически утапливаются (`transform: scale(0.95-0.97)` + `inset box-shadow`).
  - В активном состоянии (`.active`) — сохраняют вдавленный эффект со светодиодным неоновым кольцом/свечением (`0 0 12px var(--c-accent-glow)`).
- **Слайдеры и полосы прогресса (`.neu-slider`, `.neu-led-bar`):**
  - Трек слайдера всегда вдавлен в корпус (`inset 2px 2px 4px ...`).
  - Ползунок (thumb) — выпуклый круглый переключатель с сочным акцентным градиентом и свечением при движении.
- **Карточки треков и плейлистов (`.track-item`, `.neu-card`):**
  - Скругление углов: `var(--r-md)` (12px) или `var(--r-lg)` (16px).
  - Наведение (hover): мягкое приподнятие, плавный переход (`transition: all 0.15s ease`).
  - Активный/играющий трек: класс `.playing` с вдавленным мягким фоном и анимированным зеленым эквалайзером (`.playing-indicator`).
- **Иконки:**
  - Строго векторные SVG из `lucide-vue-next`. Запрещено использовать Emoji вместо управляющих иконок.

### 3. Известные грабли и защита от регрессий (Anti-Patterns)
1. **Чистота репозитория:** Большие AI-наборы навыков (skills/datasets) хранятся **глобально** в `~/.gemini/config/skills` или игнорируются в `.gitignore` (`.agents/`). Не коммитить сотни CSV-файлов датасетов в репозиторий.
2. **Z-index и слои:** Соблюдать шкалу из `design-system.css`:
   - `--z-header: 50`, `--z-player-bar: 100`, `--z-player: 1000` (полноэкранный плеер), `--z-contextmenu: 1100`, `--z-modal: 1200`. Не писать случайные `z-index: 99999`.
3. **Мобильные отступы и оверлеи:** Всегда учитывать плавающий нижний мини-плеер (`--player-height: 64px` + env safe-area). Контентные списки снизу должны иметь `padding-bottom: calc(var(--player-height) + 24px)`.
4. **Стабильность верстки:** Никаких `border: 2px` при ховере, которые сдвигают верстку соседей. Использовать `transform` или `box-shadow`.
5. **Доступность и контраст:** Основной текст (`--c-text-1`) всегда белый/почти белый (`#FFF`), второстепенный (`--c-text-2`) — `#B0B0B0`. Не допускать серого текста `#444` на темном фоне карточек `#1A1A1A`.

## 🛠 Локальная разработка и Dev-режим в обычном браузере
- **Запуск связки:**
  - `run_dev.bat` (пункт 4 для запуска всех окон: FastAPI + Bot + WebApp; или пункт 1 для FastAPI и пункт 3 для WebApp).
  - В `webapp/vite.config.js` настроен proxy для `/api` -> `http://localhost:8000`.
- **Авторизация в браузере (без Telegram):**
  - При открытии в обычном браузере (`localhost:5173`) Telegram `initData` отсутствует.
  - Для мгновенного входа доступен эндпоинт `POST /api/auth/dev-login` и кнопка на экране логина **«⚡ Быстрый вход (Dev Mode)»** (или ссылка `http://localhost:5173/?dev=1`).
  - Dev-логин подтягивает данные из локальной базы `tg_player.db` (по умолчанию аккаунт с библиотекой `mc_pluck`), генерирует валидный JWT и открывает интерфейс со всеми реальными треками и плейлистами.
  - Если FastAPI не запущен, фронтенд создаёт локальную мок-сессию для автономного тестирования верстки и стилей.
