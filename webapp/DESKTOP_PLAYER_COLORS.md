# 🎨 Кастомизация цветовой схемы десктопного плеера

## Основные цвета

Найди в файле `webapp/src/components/desktop/FullPlayerDesktop.vue` в секции `<style>` следующие переменные:

### 🟢 Основной акцент (Cyan/Green)
```css
/* Используется для: границы, текст, кнопки, индикаторы */
#00ff9d  /* Основной cyan-green */
```

**Где заменить:**
- `border: 2px solid rgba(0, 255, 157, 0.3)` → измени RGB на свой цвет
- `color: #00ff9d` → измени hex на свой цвет
- `background: linear-gradient(90deg, #00ff9d 0%, #00d4ff 100%)` → первый цвет градиента

### 🔵 Вторичный акцент (Blue)
```css
/* Используется для: акценты, градиенты, дополнительные элементы */
#00d4ff  /* Светло-синий */
```

**Где заменить:**
- `background: linear-gradient(90deg, #00ff9d 0%, #00d4ff 100%)` → второй цвет градиента
- `color: #00d4ff` → в контекст модулях

### 🌑 Фон
```css
/* Основной фон */
background: radial-gradient(ellipse at center, #0a1628 0%, #020408 100%);

/* Фон панелей */
background: linear-gradient(135deg, rgba(10, 25, 47, 0.95) 0%, rgba(2, 8, 20, 0.98) 100%);
```

## Быстрая замена цветовой схемы

### Вариант 1: Розово-фиолетовая схема 💜
```
Замени все:
#00ff9d → #ff00ff  (magenta)
#00d4ff → #8000ff  (purple)
```

### Вариант 2: Красно-оранжевая схема 🔴
```
Замени все:
#00ff9d → #ff4444  (red)
#00d4ff → #ff8800  (orange)
```

### Вариант 3: Желто-зеленая схема 💛
```
Замени все:
#00ff9d → #ffff00  (yellow)
#00d4ff → #88ff00  (lime)
```

### Вариант 4: Голубая схема ❄️
```
Замени все:
#00ff9d → #00ffff  (cyan)
#00d4ff → #0088ff  (blue)
```

## Инструменты для замены

### VS Code - Find & Replace
1. Открой `FullPlayerDesktop.vue`
2. Нажми `Ctrl+H` (или `Cmd+H` на Mac)
3. Find: `#00ff9d`
4. Replace: `твой_цвет`
5. Нажми "Replace All"
6. Повтори для `#00d4ff`

### Также замени rgba версии
```
rgba(0, 255, 157, X)  →  rgba(твой_R, твой_G, твой_B, X)
rgba(0, 212, 255, X)  →  rgba(твой_R, твой_G, твой_B, X)
```

Где X - это прозрачность (не меняй её!)

## HSL альтернатива (рекомендуется)

Вместо hex можно использовать HSL для лучшего контроля:

```css
/* Вместо #00ff9d */
color: hsl(160, 100%, 50%);  
/*         ^    ^     ^
           |    |     └─ Яркость (50% = средняя)
           |    └─────── Насыщенность (100% = полная)
           └──────────── Оттенок (0-360, где 160 = cyan-green)
*/

/* Примеры оттенков: */
0°   = Красный
30°  = Оранжевый
60°  = Желтый
120° = Зеленый
180° = Cyan
240° = Синий
280° = Фиолетовый
320° = Розовый
```

### Пример HSL замены:
```css
/* Старый */
color: #00ff9d;
border-color: rgba(0, 255, 157, 0.3);

/* Новый (фиолетовая схема) */
color: hsl(280, 100%, 50%);
border-color: hsl(280, 100%, 50%, 0.3);  /* С прозрачностью */
```

## Эффекты свечения

Измени box-shadow для соответствия новому цвету:
```css
/* Старый */
box-shadow: 0 0 20px rgba(0, 255, 157, 0.4);

/* Новый (с твоим цветом) */
box-shadow: 0 0 20px rgba(твой_R, твой_G, твой_B, 0.4);
```

## Градиенты

Для градиентов используй два близких оттенка:
```css
/* Монохромный градиент (один цвет, разная яркость) */
background: linear-gradient(135deg, hsl(160, 100%, 50%) 0%, hsl(160, 80%, 30%) 100%);

/* Двухцветный градиент (соседние оттенки) */
background: linear-gradient(135deg, hsl(160, 100%, 50%) 0%, hsl(200, 100%, 50%) 100%);
```

## Автоматизация

Можно создать CSS переменные в начале стиля:
```css
<style scoped>
.fullplayer-desktop {
  --primary-color: #00ff9d;
  --secondary-color: #00d4ff;
  --primary-rgb: 0, 255, 157;
  --secondary-rgb: 0, 212, 255;
}

/* Затем использовать */
.hud-btn {
  border-color: var(--primary-color);
  box-shadow: 0 0 15px rgba(var(--primary-rgb), 0.3);
}
</style>
```

Это позволит менять цвета в одном месте!
