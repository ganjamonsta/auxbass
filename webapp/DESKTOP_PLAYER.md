# 🚀 Футуристичный Десктопный Плеер

## Возможности

### 🎨 Дизайн в стиле космической панели управления
- Футуристичные неоновые границы (cyan/green)
- Анимированная сетка на фоне
- Светящиеся эффекты и тени
- Scanline эффекты на обложке
- Декоративные углы на рамках
- LCD-стиль индикаторов

### 📊 Информационные панели

#### Левая панель - Визуализация
- Большая обложка трека с рамкой
- 32-полосный аудио визуализатор
- Анимированные scanlines
- Угловые декорации в стиле HUD

#### Центральная панель - Основная информация
1. **Модуль данных трека**
   - Название и артист
   - Альбом (кликабельно)
   - Год выпуска
   - Жанр
   - Длительность
   - Битрейт
   - Количество прослушиваний
   - Индикаторы HD и "Любимое"

2. **Модуль управления воспроизведением**
   - Дисплей времени в стиле терминала
   - Прогресс-бар с буфером
   - Кнопки управления: shuffle, prev, play/pause, next, repeat
   - Большая центральная кнопка Play
   - Кнопки действий: Favorite, Add to Playlist, Download HD

3. **Модуль аудио контроля**
   - Регулятор громкости с визуализацией
   - Процентный индикатор
   - Кнопка mute

#### Правая панель - Очередь и статистика
1. **Модуль контекста**
   - Тип воспроизведения (Library/Playlist/Album/Artist)
   - Название контекста
   - Количество треков

2. **Модуль очереди**
   - Вкладки: UP NEXT / HISTORY
   - Список следующих треков
   - История прослушанных
   - Обложки треков
   - Поддержка lazy shuffle mode
   - Кликабельные элементы для перехода

3. **Модуль статистики**
   - Buffer статус
   - Битрейт
   - Количество прослушиваний
   - Режим воспроизведения (Shuffle/Repeat/Normal)

### ⚡ Функциональность

#### Навигация
- Клик на альбом → переход к альбому
- Клик на артиста → переход к артисту
- Клик на трек в очереди → воспроизведение

#### Управление
- Полный контроль воспроизведения
- Перетаскивание прогресс-бара
- Регулировка громкости
- Переключение shuffle/repeat
- Добавление в избранное
- Добавление в плейлист
- Скачивание HD версий

#### Контекстное меню
- Редактирование трека
- Удаление трека
- Скачивание
- Переход к артисту/альбому
- Добавление в плейлист

### 🎭 Анимации
- Плавные переходы между состояниями
- Пульсирующие индикаторы статуса
- Анимированный фон-сетка
- Движущиеся glow эффекты
- Спиннеры загрузки в стиле sci-fi
- Hover эффекты на кнопках

### 💾 Адаптивность
- Автоматическая подстройка под разрешение
- Отдельная версия для мобильных
- Desktop-only компонент (не влияет на мобилку)

### 🎯 Особенности

#### Цветовая схема
- Основной: cyan (#00ff9d)
- Акцент: blue (#00d4ff)
- Фон: темно-синий градиент
- Текст: белый с различной прозрачностью

#### Типографика
- Monospace шрифты для терминальных элементов
- Uppercase для лейблов
- Letter-spacing для футуристичного вида

#### Интерактивность
- Все кнопки с hover эффектами
- Светящиеся borders при наведении
- Box shadows с glow эффектом
- Smooth transitions

## Использование

Компонент автоматически используется на desktop при открытии полноэкранного плеера:
- Нажми на кнопку expand в нижнем плеере
- Или используй хоткей (если настроен)

На мобильных устройствах продолжает работать оригинальный FullPlayer компонент.

## Технические детали

- **Файл**: `webapp/src/components/desktop/FullPlayerDesktop.vue`
- **Интеграция**: Автоматическая через `App.vue` с условием `isDesktop`
- **Зависимости**: Vue 3, Pinia stores, роутер
- **Совместимость**: Chrome, Firefox, Edge (современные браузеры)
